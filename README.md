# 🎮 Tlaucer Minecraft Server

Selamat datang di **Tlaucer Minecraft Server**! Server ini menggunakan **offline mode**, jadi kamu bisa main tanpa akun Minecraft premium.

## Cara Join

### Persyaratan
- **Tlaucer Launcher** (download dari [GitHub Tlaucer](https://github.com/tlaucer/tlaucer-releases/releases))
- Koneksi internet stabil

### Langkah-langkah

1. **Download & Install Tlaucer Launcher**
2. **Buka Tlaucer Launcher**

3. **Tambah Server Baru**
   ```
   Server Name: Tlaucer Server
   Server Address: mcu.utc.web.id
   Port: 8443
   ```

4. **Masuk dengan Username Bebas** (offline mode)

5. **Klik Connect & Mulai Bermain!**

|---------|--------|
